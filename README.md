# Engineering Toolkit

## English
A fast, library-free engineering website built with plain HTML, CSS and JavaScript.

- **Unit converter**: length, mass, area, volume, speed, pressure, energy and temperature. Live results for every unit.
- **Ohm's law and power**: enter any two of V, I, R, P and the other two are calculated, with an interactive triangle.
- **Area and volume**: circle, rectangle, sphere, cylinder and cone, with a drawing of each shape.
- **Resistor color code**: pick four bands and read the value and tolerance range.
- Light mode and blueprint (dark) mode, responsive layout, and input validation (no letters, no negative values; temperature may be negative).

**Run:** open `index.html` in a browser.
**Publish:** GitHub repo → Settings → Pages → Branch `main`, folder `/ (root)` → Save.

## العربية
موقع هندسي سريع مكتوب بـ HTML و CSS و JavaScript من غير أي مكتبات.

- **محوّل وحدات**: طول، كتلة، مساحة، حجم، سرعة، ضغط، طاقة، حرارة، والنتيجة تتحدّث لحظياً لكل الوحدات.
- **قانون أوم والقدرة**: أدخل أي قيمتين من (V, I, R, P) ويحسب الباقي، مع مثلث تفاعلي.
- **المساحة والحجم**: دائرة، مستطيل، كرة، أسطوانة، مخروط، مع رسم لكل شكل.
- **ألوان المقاومات**: اختار أربع حلقات ويطلع لك القيمة ونسبة السماحية.
- وضع فاتح ووضع Blueprint داكن، تصميم متجاوب، وتحقق من المدخلات (بدون حروف أو قيم سالبة، ما عدا الحرارة).

**التشغيل:** افتح `index.html` في المتصفح.
**النشر:** من الـ repo ← Settings ← Pages ← Branch `main` والمجلد root ← Save.
